# Block storage on Chameleon

In this tutorial, we will practice using block storage on Chameleon.

Block storage is useful for giving long-lived services (like Jupyter) a persistent filesystem, and for persisting platform services that run on VM instances (e.g. MLFlow, Prometheus, etc.).

To run this experiment, you should have already created an account on Chameleon, and become part of a project. You should also have added your SSH key to the KVM@TACC site and the CHI@TACC site.

Follow along at [Block storage on Chameleon](https://teaching-on-testbeds.github.io/data-persist-chi/block/).

This tutorial uses: one `m1.medium` VM at KVM@TACC and one floating IP, and one 2 GiB block storage volume at KVM@TACC.
