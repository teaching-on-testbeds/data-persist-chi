# Object storage on Chameleon

In this tutorial, we will practice using object storage on Chameleon.

Object storage is useful when we want to persist large training data sets beyond the lifetime of any one compute instance.

To run this experiment, you should have already created an account on Chameleon, and become part of a project. You should also have added your SSH key to the KVM@TACC site and the CHI@TACC site.

Follow along at [Object storage on Chameleon](https://teaching-on-testbeds.github.io/data-persist-chi/object/).

This tutorial uses: one `m1.large` VM at KVM@TACC and one floating IP, and one object store container at CHI@TACC.
